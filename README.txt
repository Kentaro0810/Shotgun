LAST CHAMBER v1.0.0

完全オリジナルの1人用ブラウザ心理戦ゲームです。

遊び方:
1. index.html をブラウザで開く。
2. 難易度と生命数を選び「ゲーム開始」。
3. 実弾・空包の残数と使用済み弾を考え、撃つ対象かアイテムを選ぶ。
4. 相手の生命を0にすると勝利。

公開方法: このフォルダの index.html と README.txt をGitHubリポジトリ直下へアップロードし、Settings > Pages > Deploy from a branch > main / root を選択。

仕様: 外部ライブラリ、画像、通信、保存機能なし。PC/iPad対応。
