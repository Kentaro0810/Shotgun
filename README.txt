LAST CHAMBER v1.3.0 対戦・BOT強化版

主な追加
- BOT強さを5段階化: ROOKIE / EASY / STANDARD / HARD / MASTER
- 1本、2本、3本、5本先取を選択可能
- ラウンドごとのスコア表示
- 奇数ラウンドはプレイヤー、偶数ラウンドはBOTが先攻
- ラウンド終了後も設定した先取本数まで対戦継続

BOT最適化
- 各アイテムを状況別に点数評価
- 確定弾、実弾率、双方の生命、装甲、過圧、妨害状態、所持品を判断材料に使用
- 難易度ごとにアイテム使用率、攻撃基準、判断ミス率を変更
- MASTERは意図的な判断ミスなし。確定実弾は相手、確定空包は自分へ撃つ
- 不要な重ね掛けや使用不能アイテムを避ける

導入
ZIP内のindex.htmlで旧版を置き換えてください。GitHub Pagesで旧版が残る場合はURL末尾に?v=1.3.0を付けてください。
